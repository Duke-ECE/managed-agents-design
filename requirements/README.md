# Requirements

Each requirement has one directory containing its overview, design, decisions,
and delivery record. A requirement can span any number of code repositories.

| ID | Requirement | Status |
| --- | --- | --- |
| 0001 | [Durable Context Compaction](0001-durable-context-compaction/README.md) | Draft |
| 0002 | [Third-party chat SDK](0002-third-party-chat-sdk/README.md) | Draft |
| 0003 | [Managed Agents CLI](0003-managed-agents-cli/README.md) | Implementing |

To start a requirement, copy the complete root-level [template/](../template/README.md)
directory to `requirements/NNNN-descriptive-slug/`, fill in the documents, and add an index row.
The template is a complete requirement directory, not an actual requirement.

Status values: Draft, Accepted, Implementing, Completed, Deferred, Cancelled.
Keep requirement paths stable after completion. Add assets only when needed.
